# Hand Gesture Recognition using Python and OpenCV

## Project Overview

This project is a real-time Hand Gesture Recognition System developed using Python, OpenCV, and Machine Learning. The system captures hand gestures through a webcam, trains a machine learning model on collected gesture images, and predicts gestures live on screen.

---

## Features

- Real-time webcam gesture detection
- Custom gesture data collection
- Machine Learning based prediction
- Live gesture name display
- Easy to train with new gestures

---

## Technologies Used

- Python
- OpenCV
- NumPy
- Scikit-learn
- Joblib
